# Pokédex Explorer

## Autor
Rafael Augusto Santana Gil — Matrícula RA 22508717

## Descrição
Uma aplicação frontend interativa que permite pesquisar Pokémon em tempo real, exibindo foto, número de ID, tipo elementar, altura, peso e habilidade principal.

## API utilizada
- **PokeAPI:** https://pokeapi.co/docs/v2
- **Endpoint:** `https://pokeapi.co/api/v2/pokemon/{termo}`

## Funcionalidades
- Busca por nome ou ID.
- Exibição de 4+ informações distintas extraídas do JSON (Imagem, Tipos, Altura, Peso, Habilidade).
- Tratamento de erro amigável para Pokémon inexistente.
- Interface responsiva em Dark Mode.

## Como executar localmente
1. Clone o repositório: `git clone https://github.com/Auggusti0G/bootcamp2-app.git`
2. Abra o arquivo `index.html` em qualquer navegador.
